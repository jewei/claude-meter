# Install Claude Meter

Use these steps to install Claude Meter on macOS 14 or later:

1. Download `ClaudeMeter-<version>.dmg` from the [latest
   release](https://github.com/jewei/claude-meter/releases/latest).
2. Open the DMG.
3. Drag **Claude Meter** into **Applications**.
4. Open **Claude Meter**. The meter appears in the menu bar with no Dock icon.
5. Open **Settings**, then **Data**, to connect a provider.

[Provider credentials and recovery](providers.md) describes each credential source.
